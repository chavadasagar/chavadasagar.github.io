## 💻 Running & Developing Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/chavadasagar/chavadasagar.github.io.git
   cd chavadasagar.github.io/mysite
   ```
2. Open any sub-project `index.html` directly in a modern web browser, or serve using any static HTTP server:
   ```bash
   npx serve .
   ```

### Adding a New Project

Scaffold a new project automatically with standard files (`index.html`, `style.css`, `script.js`, `README.md`):
```bash
python scripts/manage_md.py init <new-folder-name> "Optional Title"
```
