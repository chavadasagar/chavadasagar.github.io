# Mr. Gill's Heritage Kitchen — Restaurant Website

A warm, rich Punjabi dhaba style website and table reservation portal for Mr. Gill's Heritage Kitchen, located in Jawahar Ground area, Bhavnagar, Gujarat.

---

## 🚀 Key Features

- **Heritage Token Palette**: Deep sarsariya brown (`#2C1810`), warm cream (`#FFF8F0`), tandoor red (`#C8351A`), and saffron gold (`#D4A017`).
- **Typography**: Playfair Display 700 Italic for classic restaurant headlines and Lato for clean menu readability.
- **Dhaba Chalkboard Menu Layout**: Dish listings with gold divider rules, ingredients description, and saffron gold prices.
- **WhatsApp Table & Party Reservation**: Direct reservation submission opening pre-filled WhatsApp message.
- **100% Client-Side**: Operates entirely in browser memory with zero backend requirements.

---

## 🛠️ Technology Stack

- **Markup**: HTML5 with semantic tags & local business schema
- **Styling**: CSS3 (Playfair Display & Lato Google Fonts, gold rule accents)
- **Logic**: Vanilla JavaScript (ES6+ menu category tab filtering & reservation handler)
