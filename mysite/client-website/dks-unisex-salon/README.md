# DKs Unisex Salon — Premium Salon Website

A high-end editorial website and appointment booking portal for DKs Unisex Salon, located in Shivalay Complex, Ambawadi Road, Bhavnagar, Gujarat.

---

## 🚀 Key Features

- **Editorial Luxury Token System**: True black (`#0F0F0F`), off-white (`#F7F5F2`), champagne gold (`#B89A6A`), and pale gold (`#EDE0CB`).
- **Typography**: Cormorant Garamond display serif headlines paired with modern Jost geometric body typeface.
- **50/50 Split Hero**: Editorial visual showcase left, value proposition and 4.9-star review proof right.
- **Tabbed Service Catalog**: Seamless switching between Hair Styling, Skin/Hydrafacial, Bridal Makeup, Nail Art, and Kids Grooming.
- **Stat Tiles & Social Proof**: 519+ reviews, 4.9 stars rating tile strip.
- **WhatsApp Appointment Booking**: Form validation with instant pre-filled WhatsApp messaging to the salon manager.

---

## 🛠️ Technology Stack

- **Markup**: HTML5 with semantic tags & local business schema
- **Styling**: CSS3 (Cormorant Garamond & Jost Google Fonts, CSS variables)
- **Logic**: Vanilla JavaScript (ES6+ tab switching & appointment handler)
