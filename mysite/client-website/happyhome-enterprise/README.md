# Happyhome Enterprise — Hardware & Sanitaryware Shop Website

A modern, industrial-styled showcase website and online quotation request portal for Happyhome Enterprise, a top-rated hardware and sanitaryware shop located in Sanskar Mandal, Bhavnagar, Gujarat.

---

## 🚀 Key Features

- **Industrial Token Palette**: Deep steel navy (`#1A1A2E`), burnt orange (`#E07B39`), and light grey-white (`#F0F4F8`) with zero border-radius product cards.
- **Product Category Showcase**: Grid listing Sanitaryware, Architectural Hardware, CPVC Plumbing Pipes, Paints, Electricals, and Bathroom Tiles.
- **Interactive Product Catalog**: Filter products by category and click "Get Quote" to auto-fill the quotation request form.
- **WhatsApp Quotation Integration**: Pre-fills quotation details and opens WhatsApp directly to send queries to the shop manager.
- **100% Client-Side**: No backend server required. Built using semantic HTML5, modern CSS3, and vanilla JS.

---

## 🛠️ Technology Stack

- **Markup**: HTML5 with OpenGraph & Schema.org metadata
- **Styling**: CSS3 (Rajdhani & DM Sans Google Fonts, CSS custom variables)
- **Logic**: Vanilla JavaScript (ES6+ DOM manipulation & event handlers)
