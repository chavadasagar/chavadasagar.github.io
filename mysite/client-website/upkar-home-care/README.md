# Upkar Home Care Service — Home Care & Nursing Website

A trustworthy, family-oriented website and home caregiver request portal for Upkar Home Care Service in Bhavnagar, Gujarat.

---

## 🚀 Key Features

- **Home & Care Token Palette**: Deep forest green (`#2D4A3E`), light mint-white (`#F3F8F5`), growth green (`#4DAA7A`), and warm amber (`#E8A44A`).
- **Typography**: Lora 600 warm serif for headlines and Source Sans 3 for clean body legibility.
- **Service Offering Cards**: Maid Service, Patient Care, Elderly Care, Baby Care, Post-Surgery Nursing, and Deep Home Cleaning.
- **Trust Signals Strip**: Verified Staff, Background Checked, and Local & Trusted badge showcase.
- **3-Step Onboarding Process**: 01 Call / Enquire → 02 We Match You → 03 Service Begins.
- **WhatsApp Care Giver Booking**: Form validation with pre-filled WhatsApp inquiry generation.

---

## 🛠️ Technology Stack

- **Markup**: HTML5 with semantic tags & local service schema
- **Styling**: CSS3 (Lora & Source Sans 3 Google Fonts, amber highlights)
- **Logic**: Vanilla JavaScript (ES6+ care request validation & WhatsApp handler)
