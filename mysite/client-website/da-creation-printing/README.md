# D A CREATION — Graphic Design & Printing Studio Website

A high-contrast design studio website and print specification quotation portal for D A CREATION, located in Bhavnagar, Gujarat.

---

## 🚀 Key Features

- **Design Studio Token Palette**: Pure black (`#121212`), studio card surface (`#1E1E1E`), and press electric yellow (`#FFDD00`).
- **Typography**: Single-family Space Grotesk 700/500/400 geometric design-forward typography.
- **2x3 Service Grid**: 4px electric yellow left-border cards covering Logo Design, Brochure Printing, Flex Banners, Business Cards, Social Media Graphics, and Packaging.
- **4-Step Process Flow**: 48px yellow numbered steps (01 Brief → 02 Design → 03 Proofing → 04 Print & Deliver).
- **Print Spec WhatsApp Quote System**: Form fields for size, GSM paper type, quantity, and design specifications.

---

## 🛠️ Technology Stack

- **Markup**: HTML5 with semantic tags & local business schema
- **Styling**: CSS3 (Space Grotesk Google Fonts, electric yellow border accents)
- **Logic**: Vanilla JavaScript (ES6+ print quote calculator & WhatsApp handler)
