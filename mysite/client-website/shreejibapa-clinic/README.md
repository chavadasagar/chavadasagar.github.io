# Shreejibapa Clinic — Multi-Specialty Clinic Website

A medical multi-specialty and aesthetic clinic website for Shreejibapa Clinic, established in 2007 near Nandkuvarba Mahila College, Bhavnagar, Gujarat.

---

## 🚀 Key Features

- **Clinical Token Palette**: Medical teal-navy (`#003B5C`), cool white (`#F4F8FB`), health teal (`#00A896`), and light teal (`#B2EBE6`).
- **Typography**: Merriweather 700 authoritative serif for doctor titles paired with clean Inter body typeface.
- **Specialty Icon Grid**: 6 circular icon tiles covering Dermatology, Cosmetology, Joint & Pain Care, Hair PRP, Weight Management, and Psychology.
- **Horizontal Doctor Profile Card**: Photo showcase left with MBBS, Fellowship, and 16+ years experience credentials right.
- **WhatsApp Doctor Appointment Booking**: Client-side validation and instant pre-filled WhatsApp consultation booking.

---

## 🛠️ Technology Stack

- **Markup**: HTML5 with MedicalWebPage schema markup
- **Styling**: CSS3 (Merriweather & Inter Google Fonts, circular icon tiles)
- **Logic**: Vanilla JavaScript (ES6+ appointment validation & WhatsApp handler)
