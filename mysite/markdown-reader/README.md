# Modern Markdown Reader

A browser-based Markdown Reader web utility built with vanilla HTML, CSS, and JavaScript.

---

## 🚀 Key Features

- **100% Client-Side**: Operates entirely within the browser with zero server data transfer.
- **Manual MD Paste & Raw Editor**: Directly paste raw Markdown text or edit existing document drafts with clipboard support (`Ctrl+V` capture & `Ctrl+E` editor shortcut).
- **Enlarged Presentation Mode**: Widescreen slide presentation deck with dynamic sizing and responsive layout.
- **Full Width & Reading Width Toggles**: Customize document max read width up to 1800px or toggle full width viewing.
- **Responsive Layout**: Designed for seamless use on desktop, tablet, and mobile browsers.
- **Intuitive UI**: Modern aesthetic built for quick and efficient workflow.

---

## 🛠️ Technology Stack

- **Markup**: HTML5
- **Styling**: CSS3 (Flexbox / Grid / Custom Variables)
- **Logic**: Vanilla JavaScript (ES6+)

---

## 💻 How to Run Locally

1. Open `index.html` directly in any modern browser.
2. Alternatively, serve using Live Server or any static HTTP server:
   ```bash
   npx serve .
   ```
