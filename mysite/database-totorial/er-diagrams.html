Entity Relationship (ER) Diagram Learning

Visualize how tables connect, understand cardinality (1:1, 1:N, N:M), and learn foreign key placements.

Interactive Entity Relationship Visualizer

One-to-One (1:1)

One record in Table A relates to exactly one record in Table B. Often used for sensitive user credentials or isolated profiles.

users (user_id PK) ↔ auth_credentials (user_id PK/FK)

One-to-Many (1:N)

One record in Table A relates to multiple records in Table B. The Foreign Key is placed in Table B (the child table).

users (user_id PK) ➔ orders (user_id FK)

Many-to-Many (N:M)

Multiple records in Table A relate to multiple records in Table B. Requires an intermediate Junction Table containing Foreign Keys to both.

products ↔ product_categories ↔ categories
