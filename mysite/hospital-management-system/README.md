# Aegis Health

A browser-based Hospital Management System web utility built with vanilla HTML, CSS, and JavaScript.

---

## 🚀 Key Features

- **100% Client-Side**: Operates entirely within the browser with zero server data transfer.
- **Responsive Layout**: Designed for seamless use on desktop, tablet, and mobile browsers.
- **Intuitive UI**: Modern aesthetic built for quick and efficient workflow.

---

## 🛠️ Technology Stack

- **Markup**: HTML5
- **Styling**: CSS3 (Flexbox / Grid / Custom Variables)
- **Logic**: Vanilla JavaScript (ES6+)

---

## 💻 How to Run Locally

1. Open `index.html` directly in any modern browser.
2. Alternatively, serve using Live Server or any static HTTP server:
   ```bash
   npx serve .
   ```
