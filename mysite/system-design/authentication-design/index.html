Registration Flow

User signup karta hai, password hash hota hai aur email verification link jaata hai. Tables: Users, EmailVerifications, UserRoles, AuditLogs.

Endpoint

POST /api/auth/register
{ "email": "a@b.com", "password": "Str0ng@Pass", "name": "Sagar" }
POST /api/auth/verify-email?token=xxxx

Login Flow

Sabse important flow. Isme lockout, verification aur MFA ke checks hote hain. Tables: Users, LoginAttempts, RefreshTokens, UserSessions.

Endpoint

POST /api/auth/login
{ "email": "a@b.com", "password": "..." }
200 -> { "accessToken": "...", "refreshToken": "...", "expiresIn": 900 }
Error me hamesha same message do: "Invalid email or password". Isse attacker ko pata nahi chalta ki email exist karta hai ya nahi.

Refresh Token Rotation Flow

C# Sample

var claims = new[] {
  new Claim(JwtRegisteredClaimNames.Sub, user.Id.ToString()),
  new Claim(ClaimTypes.Email, user.Email),
  new Claim(ClaimTypes.Role, "Admin")
};
var key   = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(cfg["Jwt:Key"]));
var token = new JwtSecurityToken(
  issuer: cfg["Jwt:Issuer"], audience: cfg["Jwt:Audience"],
  claims: claims, expires: DateTime.UtcNow.AddMinutes(15),
  signingCredentials: new SigningCredentials(key, SecurityAlgorithms.HmacSha256));
return new JwtSecurityTokenHandler().WriteToken(token);

Forgot / Reset Password

Tables: PasswordResetTokens, Users, RefreshTokens.

Endpoints

POST /api/auth/forgot-password   { "email": "..." }
POST /api/auth/reset-password    { "token": "...", "newPassword": "..." }
POST /api/auth/change-password   { "oldPassword": "...", "newPassword": "..." }

Password Policy

Minimum 8-12 characters, upper + lower + number + symbol, common passwords block karo, aur last 3-5 passwords reuse mat hone do.

MFA / 2FA

Password ke baad doosra proof. Types: Email OTP, SMS OTP, TOTP (Google Authenticator), Backup codes. Table: UserMfa.

Endpoints

POST /api/auth/mfa/setup      -> secret + QR code
POST /api/auth/mfa/enable     { "code": "123456" }
POST /api/auth/mfa/verify     { "mfaToken": "...", "code": "123456" }
