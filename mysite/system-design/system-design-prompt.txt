Sections is order me:

1. Overview (Big Picture)
   - Module kya karta hai, kaun use karta hai, 1 paragraph
   - Poore module ka ek architecture/flow diagram

2. Tables
   - Har table ka purpose, columns, PK/FK, sample 2-3 rows
   - ER diagram

3. Flow
   - Main flow ka flowchart
   - Har important operation ka sequence diagram (User → UI → API → DB)
   - Status/state diagram (agar status columns hain)

4. Screens
   - Kitni screens, har screen ka kaam
   - Navigation flow (screen se screen)

5. API Endpoints
   - Har endpoint: method, URL, request JSON, success response, error responses

6. API-to-Table Mapping (matrix)
   Columns: Endpoint + HTTP method | Business operation | Tables read | 
   Tables inserted | Tables updated | Tables deleted/revoked | 
   Kis condition me DB operation trigger hoga

7. Screen-to-Table + Validation (matrix)
   Columns: Screen | User action | Kaunse table me insert/update | 
   Validation rule | Error message (user ko dikhne wala)

8. Transaction Boundary Matrix
   Columns: Business operation | Ek transaction me kaunse changes | 
   Atomicity required? | Commit ke baad kya hoga | Email/SMS fail ho to kya | 
   Retry se duplicate ka risk | Idempotency kaise implement hogi

9. Edge Cases & Failure Scenarios
   - Double click, network timeout, partial failure, concurrent request

10. Folder Structure
   - Tree view (Clean Architecture), har folder ke saamne 1 line ka kaam
