Subscription Tutorial

Subscription Module

1. Overview (Big Picture)

Yaad rakhne wali baat: Subscription = user ek plan leta hai, har period pe paise kat-te hain, aur access status se control hota hai. Status hi sabka boss hai.

Hum ek hi scenario poore tutorial me use karenge: Rahul Shah "NoteNest" app me Pro Monthly (₹499/month) plan leta hai, payment hota hai, har mahine renew hota hai, aur baad me cancel kar deta hai. Ye module user ko plans dikhata hai, subscribe karwata hai, payment record karta hai, renewal background job se chalata hai, aur cancel handle karta hai. Use karne wale: end-user (Rahul), admin (support), aur payment gateway (webhook se).

8. Transaction Boundary Matrix

Yaad rakhne wali baat: DB changes ek transaction me. Email/SMS transaction ke baad, aur fail ho to business operation rollback nahi hota.

Yaad rakhne wali baat: Network kabhi bhi fail ho sakta hai. Har operation ko "do baar chale to bhi safe" banao.

10. Folder Structure

Yaad rakhne wali baat: Dependency andar ki taraf: Api → Application → Domain. Domain kisi ko nahi jaanta.
Subscription.sln
├─ Subscription.Domain          # Entities, enums, rules (no EF, no packages)
│  ├─ Entities/                 # Plan, Subscription, Payment, SubscriptionEvent
│  └─ Enums/                    # SubscriptionStatus (Pending, Active, ...)
├─ Subscription.Application     # Business use-cases (CQRS)
│  ├─ Commands/                 # CreateSubscription, CancelSubscription
│  ├─ Queries/                  # GetPlans, GetMySubscription
│  ├─ Interfaces/               # IPaymentGateway, IEmailSender, IAppDbContext
│  └─ Validators/               # FluentValidation rules
├─ Subscription.Infrastructure  # Bahar ki duniya se baat
│  ├─ Persistence/              # EF Core DbContext, migrations (PostgreSQL)
│  ├─ Payments/                 # Gateway client implementation
│  ├─ Messaging/                # Email/SMS sender, outbox
│  └─ Jobs/                     # RenewalJob (background service)
└─ Subscription.Api             # Controllers, middleware
   ├─ Controllers/              # SubscriptionsController, WebhooksController
   └─ Middleware/               # Idempotency, global error handler
