# Vyunix Technologies Website

A refined static website for Vyunix Technologies built with HTML, CSS and vanilla JavaScript.

## Run locally

Option 1:
- Open `index.html` directly in a browser.

Option 2 (recommended):
```bash
npm run dev
```

## Main improvements

- Reworked brand identity and visual hierarchy
- More credible, focused software-engineering positioning
- Responsive navigation and mobile layouts
- New services, process, work and founder presentation
- Accessible form labels, skip link and reduced-motion support
- Contact form now prepares a real email instead of showing a fake success state
- Lighter particle background and improved animation performance
- Updated SEO metadata and semantic page structure

## Contact behavior

The website is static. The contact form opens the visitor's default email app with the project details pre-filled. If you later add a backend/API, replace the form submit handler in `js/main.js`.
